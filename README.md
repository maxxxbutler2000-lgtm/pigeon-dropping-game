# Pigeon Patrol

Steer with left/right arrows. Droppings fall automatically. Earn coins, buy upgrades, unlock colorful targets, and travel through four worlds.

## Run

Requires Node.js 22 or newer. No dependencies to install.

```sh
npm start
```

Open http://localhost:3000. The server uses Railway's PORT environment variable and binds to 0.0.0.0. Railway can deploy the included Dockerfile directly. Health check: /health.

Progress saves in browser local storage. Saves on the original ChatGPT Site do not automatically transfer to the Railway domain.
